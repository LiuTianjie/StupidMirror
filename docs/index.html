06 / FAQ

Common questions.

Does StupidMirror work without a cable?

Yes. Run Set Up This iPhone once over USB, then keep the iPhone and the Mac on the same network and mirror it over Wi-Fi. Wireless audio is not available.

When are Camera and Microphone permissions needed?

iPhone video over USB or Wi-Fi needs neither permission. For a USB iPhone, choose Phone to keep sound on the device, or Mac to play it on this computer. Mac audio requires Camera and Microphone permissions for the USB audio source.

Does it support Android?

Yes. Android 11 or newer over ADB with USB debugging enabled. Video and device audio come from scrcpy, and control uses Appium with UiAutomator2.

Which AI agents can use it?

Codex through the bundled plugin, which shows the live phone screen inside the chat, and Claude Code or other MCP clients through the local MCP server. StupidMirror needs no model API key.

Does the screen or my data go through a cloud service?

No. The Codex panel streams over encrypted local WebRTC without a cloud relay, the MCP server listens on this Mac only, and text recognition runs locally with Apple Vision.

Is StupidMirror free?

One device can be mirrored and controlled without signing in. An SM- activation code unlocks several devices at once. The source is available under PolyForm Noncommercial, and commercial use needs separate authorization.

What do I need to run it?

A Mac with macOS 15 or newer and Xcode for iPhone or iOS Simulator support. Real iPhones need trust and Developer Mode. Both USB and Wi-Fi iPhone video require a signed screen agent prepared through Set Up This iPhone over USB; accessibility automation and compatibility control use that agent too.
