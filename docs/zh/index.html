06 / FAQ

常见问题。

需要一直插线吗？

不需要。先用 USB 完成一次「设置这台 iPhone」，之后让 iPhone 和 Mac 处在同一网络，就能通过 Wi-Fi 镜像。无线方式暂不支持声音。

为什么要摄像头权限？

macOS 把通过 USB 连接的 iPhone 屏幕当作一种摄像头式的采集源。StupidMirror 读取的是这个采集源，不会使用 Mac 的摄像头。

支持 Android 吗？

支持。Android 11 及以上，开启 USB 调试后通过 ADB 连接。画面和声音来自 scrcpy，控制通过 Appium 与 UiAutomator2。

哪些 AI Agent 可以用？

Codex 可以通过内置插件使用，聊天里能直接看到手机实时画面；Claude Code 和其他 MCP 客户端通过本机 MCP Server 接入。StupidMirror 本身不需要模型 API Key。

画面和数据会经过云端吗？

不会。Codex 面板通过加密的本地 WebRTC 传输画面，没有云端中转；MCP Server 只监听本机；文字识别用 Apple Vision 在本地完成。

StupidMirror 免费吗？

单台设备无需登录即可镜像和控制。SM- 激活码可以解锁多台设备同时使用。源码以 PolyForm Noncommercial 许可公开，商业使用需要另行授权。

运行需要什么条件？

一台 macOS 15 或更新版本的 Mac。iPhone 无线镜像和控制还需要在手机上开启开发者模式，并在 Mac 上有 Apple Development 签名身份；使用模拟器需要 Xcode。
